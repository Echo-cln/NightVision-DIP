# 夜视大师 · Web 前端

已将确认的手机界面整理为 HTML、CSS 和原生 JavaScript ES Modules 项目。无需安装前端依赖；没有 React/Vue 运行时或外部 CDN。页面保留原版绿、莓酒红、暖棕金三种主题。

## 运行

需要 Node.js 20 或更新版本。

```bash
git clone https://github.com/Echo-cln/NightVision-DIP.git
cd NightVision-DIP
git switch feat/mobile-web
cd web
npm run dev
```

打开终端显示的 `http://127.0.0.1:4173`。不需要执行 `npm install`。

```bash
npm run check
npm test
npm run build
npm run preview
```

构建产物为 `web/dist/`，可以部署到任意静态 HTTPS 主机。使用相对路径，支持子目录部署。不要直接双击 `index.html`：ES Modules、Worker 和浏览器存储需要 HTTP/HTTPS 环境。摄像头预览需要 HTTPS 或本机 localhost；手机访问电脑的普通 HTTP 地址不能保证获得相机权限，可改用系统相机或相册导入。

## 当前功能

- 相册导入、系统拍照、摄像头预览，以及内置道路示例。
- 自动处理后直接显示单张结果图。
- 亮度、对比度、降噪、饱和度、色温五个滑块实时更新画面。
- 右下角拖动对比和原图／效果切换；键盘方向键也能移动分隔线。
- 大图查看、1–3 倍缩放、目标区域对比、实际处理步骤和亮度分布。
- IndexedDB 本地记录、重新打开和继续调整、记录与参数 JSON 导出、结果 JPEG 下载。
- 配对清晰参考图的 PSNR/SSIM，以及实际计算的 64×64 FFT 频谱。

已应用的视觉调整：压缩自动参数卡、把“重新自动增强”改为次级按钮、加深并适当放大辅助文字。保留原来的首页结构与配色。

## 源码结构

| 文件 | 职责 |
| --- | --- |
| `index.html` | 应用外壳、图片输入 |
| `styles/app.css` | 已确认页面样式和响应式规则 |
| `src/views.js` | 首页、编辑、记录和处理详情模板 |
| `src/app.js` | 页面交互、预览调度、相机和保存流程 |
| `src/model.js` | 状态、参数边界和状态重置 |
| `src/processing.js` | 图像处理和统计的纯函数 |
| `src/image-worker.js` | 独立线程执行图像计算 |
| `src/engine.js` | 图片解码、线程通信和结果生成 |
| `src/quality.js` | 有参考图质量评价 |
| `src/storage.js` | IndexedDB 事务、设置与旧记录元数据兼容 |
| `src/dom.js`、`src/icons.js` | DOM、文件下载、图标 |

内联事件已移除，按钮通过 `data-action` 和统一事件监听连接。图像计算优先由 Web Worker 执行；线程不可用时允许在主线程重试。保存前等待最后一次调整完成，不把原图查看状态当作下载内容。

## 处理范围

前端实际执行 Gamma、亮度通道直方图均衡、对比度、灰度世界白平衡、饱和度、色温、3×3 高斯／中值滤波。`图像复原` 页当前执行亮度与颜色校正；**尚未接入运动模糊维纳反卷积、CLAHE 或同态滤波**，不提供这些算法的占位按钮。

照片不发送到服务器。原始导入数据独立保留；交互预览的长边上限为 640 像素，首次处理为 960 像素，下载与保存记录前按最多 1600 像素重新计算。结果使用 JPEG，透明图片的透明通道不会保留在导出文件中。清理浏览器网站数据会删除本地记录。

亮度、暗部比例和残差噪声参考值只能描述变化，不代表质量必然改善。PSNR 使用 RGB 像素，SSIM 使用亮度、8×8 非重叠窗口，评价采样长边最多 256 像素；必须自行确认参考图的场景和像素位置一致。频谱显示与频域增强是不同功能。

## 验证状态

已配置源码语法／路径检查、算法和状态单元测试、真实 Worker 消息与可转移像素缓冲区测试，以及静态构建。浏览器自动化环境无法连接此工作区的本地开发服务器，尚未完成浏览器视觉、相机权限和真机下载验收。

建议真机验收顺序：

1. 打开首页切换三个主题。
2. 导入一张暗图，确认自动处理后显示单张结果。
3. 使用右下角原图切换和拖动对比，退出后回到单图。
4. 切换手动调控，连续调整五个滑块，再重置。
5. 快速调整后立即保存图片，确认下载结果与最后的参数一致。
6. 保存记录、刷新、重新打开，继续调整并更新记录。
7. 在 HTTPS 真机访问时检查拍照权限和系统相机回退。
