# 低照度增强模块

## 运行与分工

以根目录 `app/` 原生 Android 客户端为准；`web/` 保留旧版参考，不参与 APK 运行。

- `ImageProcessor.process(image, ENHANCE, ProcessParameters())`：自动增强。
- `ImageProcessor.recommend(image, ENHANCE)`：从完整工作图生成推荐参数。
- `EnhancementPolicy`：增强模块独立的质量信号、自动策略与解释。
- `LuminanceChannel`：全范围 BT.601 YCbCr 的 Y、HSV 的 V 及彩色重建。
- `ProcessResult`：结果图和处理报告；`effectiveParameters` 为真正执行的参数，可重放。
- 复原模块继续走 `RESTORE`，本次不新增同态滤波或运动反卷积；已集成队友合入main的WienerMotionDeblurrer及其参数、控制项和测试。

## 图像处理

1. 分析平均亮度、标准差、暗部/高光比例和亮度直方图。
2. 在邻域变化较小的区域抽样。中心与四邻域均值的绝对残差中位数除以 `0.67449 × sqrt(1.25)`，给出噪声标准差参考；少于16个样本显示“证据不足”。排除大残差、饱和点及明显边缘。它依赖近似平坦、加性高斯假设，不能视作真实噪声测量或退化诊断。
3. 极端亮/暗的孤立像素与邻域差值较大时计入孤立极值参考，达到0.3%时选择中值滤波；否则结合Gamma局部导数估计提亮后的噪声参考，达到2时启用双边降噪（输入参考低于0.75不触发）。孤立亮点也可能是真实目标，必须结合图像观察验证。
4. 平均亮度低于105时，按 `gamma = log(105/255) / log(mean/255)` 并限制在0.48～1生成提亮参数；均值小于1保持黑场。不会叠加固定亮度和曝光把黑画面整体抬灰。自动模式对低于约15灰阶使用平滑暗端过渡，并在近黑区域减弱CLAHE，避免把JPEG相邻量化值放大成明显条带。亮度正常时允许保持原样。平均亮度低于35、暗部超过75%且场景存在明显亮暗差异时，禁用自动局部均衡并将Gamma下限设为0.6，保守处理严重欠曝图，降低噪声和压缩量化放大。
5. 偏暗、标准差在2～45且4×4区域均值跨度大于8时，选择温和CLAHE；按噪声参考调整裁剪值及20%～35%混合强度。该跨度也受场景内容影响，只是启发式策略，不是照明分解。
6. 先降噪，再执行亮度映射和Gamma。YCbCr模式保持色度差，超出RGB色域时等比缩小色度；HSV模式保持H/S并映射V。手动模式可切换两者。

自动模式默认YCbCr，不自动叠加色彩特效。手动专业参数、RGB曲线和白平衡仍可使用。历史记录保存实际执行参数（包含亮度空间及CLAHE混合强度），旧JSON缺失字段使用兼容默认值。

## 界面与本地数据

首页两个功能入口；进入后导入/拍照。默认上下显示两张完整图像，另可单看完整原图或结果，采用Fit显示，不做半图拼接。图像分析、前后直方图和执行步骤直接显示。

原始导入文件复制到应用私有目录，图片库SQLite只保存路径和信息。原图、结果分别存文件；处理记录索引和参数JSON保存在SharedPreferences，保留最近20条。删除应用数据/卸载会清除此私有数据，已导出系统相册的图片仍保留。保存索引成功后才清理过期记录文件。

大图仍沿用已有采样策略，工作图长边最多1800像素（2的幂采样，可能明显低于1800）；原始文件保留，但处理结果不是全分辨率导出。相册导出为JPEG。不能在报告中写“无损原尺寸增强”。

导入、历史打开、参数预览共享一个可取消任务与版本检查。自动预览使用完整工作图确定策略；低分辨率预览完成后仍禁止导出，直到完整工作图计算完成。保存时冻结相关操作，防止图像与参数不对应。

## 验证

纯Kotlin算法测试覆盖正常/纯黑不被强行提亮、低照度提亮、温和CLAHE选择、噪声与纹理区分、中值/双边选择、HSV色彩比例、YCbCr色域处理、色度降噪色偏回归、参数重放、小尺寸与源像素保护。完整Android编译和测试通过GitHub Actions验证。

真机仍需完成：相机权限与拒绝、EXIF横竖方向、快速换图、连续调参后立即保存、自动与手动切换、重启与历史参数恢复、相册导出、低内存及小屏布局。真实画质验收至少使用道路彩色监控、室内低光、背光人物和强反光场景；结合相同目标区域观察，不以亮度上升代替质量提升。

本地验证：53项JVM测试（含新合入的均值滤波和Wiener回归）通过（含原有测试、增强回归、参数JSON与重放测试）；实际调用同一Kotlin内核处理仓库道路照片检查输出。完整Android CI结果以对应提交为准；尚未计入真机验收。
