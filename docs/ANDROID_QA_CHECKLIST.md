# 夜视大师 · Android 原生验收清单

> 适用分支：feat/android-native。此清单用于区分“代码已实现”“CI 已通过”“真机已验收”，禁止用构建成功代替实际交互、图像质量或跨设备验收。

## 一、自动化门禁

每次候选提交需提供 GitHub Actions 运行链接与提交 SHA。

- [ ] `./gradlew :app:testDebugUnitTest` 成功。
- [ ] `./gradlew :app:assembleDebug` 成功，并能下载对应 APK。
- [ ] 单元测试覆盖中性参数不改原图、透明度、自动参数、曝光、阴影、HSL、RGB 曲线、直方图均衡、CLAHE 极端网格与平坦区域、Mean/Gaussian/Median/Bilateral 明度降噪、白平衡开关，以及 Wiener 水平/垂直合成运动模糊复原。
- [ ] 不使用未经过 Android SDK 支持的 OpenCV/AI 算法冒充已完成算法。

## 二、真机输入与拍摄

至少在一台 Android 13+ 真机实测，并记录型号、系统版本、Android Studio/Gradle 构建号。

- [ ] CameraX 首次授权、拒绝、再次授权、系统设置拒绝后的行为均正常。
- [ ] 点击拍摄按钮得到真实照片；补光灯开/关动作与相机设备支持情况一致。
- [ ] 快速退出相机能释放摄像头资源，不发生黑屏或崩溃。
- [ ] 相册选择 JPG、PNG、WebP 和 HEIC（设备支持时）可导入。
- [ ] 横竖照片和含 EXIF 方向的照片不被意外旋转。
- [ ] 大尺寸照片经过采样仍可处理，避免内存溢出；保留原始上传文件副本。

## 三、专业参数与交互

- [ ] 首页不出现主题选择；主题设置在“我的”并可跨重启保留。
- [ ] 打开图片后自动增强（可在“我的”关闭）正常。
- [ ] 编辑器图片预览固定；滑动参数面板时仍可观察效果。
- [ ] 手动模式从自动推荐参数进入，不会突然回到另一组无关默认值。
- [ ] 光线、色彩、细节、效果、算法五组参数互不串值。
- [ ] 长按看原图、分屏拖动、结果切换、导出图片均正常。
- [ ] 修改参数时旧计算任务不会覆盖较新参数结果。
- [ ] 处理未完成前禁止导出低分辨率中间预览。
- [ ] 重置单组参数不会清空其他已调整参数。
- [ ] RGB/单通道曲线各自可拖动控制点，能使处理像素变化。

## 四、画质与算法验证

禁止仅凭亮度升高判定“图像质量提升”。

- [ ] 选择至少五类真实夜景：道路监控、室内低光、背光人物、色偏夜景、强反光场景。
- [ ] 记录自动推荐参数、处理耗时及前后相同 ROI 的可辨识度主观评价。
- [ ] CLAHE 平坦区域不凭空产生纹理，局部网格切换不产生明显块边。
- [ ] 双边滤波应比高斯滤波更好保留高对比边缘；记录噪声残余与边缘保留的权衡。
- [ ] Wiener 复原分别测试水平/垂直已知匀速线性 PSF，检查 MSE 相对退化图下降；对不同 K、长度和方向做参数敏感性测试。
- [ ] 对高分辨率输入确认工作网格有上限、原图尺寸和 alpha 不变；检查极细小拖影因工作分辨率不足而被明确跳过，不得假报复原成功。
- [ ] 纯白/纯黑/小尺寸/近似单色图像不崩溃、不除零。
- [ ] 有参考实验用“干净真值 → 人工退化 → 各算法复原”的数据链，统计 PSNR/SSIM。
- [ ] 无参考夜景不要把“原图与增强图互相计算的 PSNR/SSIM”误写为质量改进指标。

## 五、图片库、记录与数据完整性

- [ ] 导入图片后 SQLite 图片库增加一条对应资产，正确显示名称、尺寸、来源。
- [ ] 收藏、筛选、名称搜索、删除确认正常；删除应用副本不会删除系统相册原图。
- [ ] 导出时 JPEG 质量按个人偏好执行。
- [ ] 保存处理记录后，重开仍可查看原图/结果、恢复曝光/Gamma/HSL/曲线/降噪/CLAHE 等完整参数。
- [ ] 清空处理记录与删除图片库资产分别作用于相应数据，不误删用户系统相册。
- [ ] 图片库容量统计更新；清理图片库后空间变化合理。
- [ ] 同一图片多次调参的导出、记录、再次导入都可追踪，不以重复数据掩盖失败。

## 六、交付证据

每一轮版本保留：Git 提交 SHA、对应 CI 链接、APK、Android Studio 构建日志、真机型号及测试日期、典型场景原图与结果、参数 JSON、问题清单、问题复测结论。

**未完成的内容**：Retinex、同态滤波、未知/空间变化 PSF 估计、复杂运动模糊建模、完整参考图配准与 PSNR/SSIM 原生测量、裁剪/透视/局部蒙版。当前 Wiener 仅针对用户指定的匀速直线运动 PSF；CI 合成数据测试不等于真机画质验收。上述未验收能力不得在答辩时表述为已通过验收。

### Android 明度均值滤波
新增 3×3 明度均值滤波，复制边界，保留 alpha；沿用降噪强度和细节参数，方法名 MEAN 随参数 JSON 保存并回填。真机需验证：选择均值后强度 0/50/100 的差异、保存记录重启回填、边缘软化及彩色高光裁剪。均值会模糊边缘，不属于运动模糊复原。
