## 1. 本阶段学什么，为什么先做模拟退化？

真实夜间照片里的噪声很复杂，通常没有一张完全无噪声的对应「真值」图像。直接对真实照片处理，难以客观判断一个滤波算法到底去掉了多少噪声、同时损失了多少细节。

因此，B1 首先从**清晰原图**出发，人工添加已知类型、强度和随机种子的噪声，得到可复现的退化图；之后才进行去噪并与原图比较 PSNR、SSIM。这属于**有参考的受控实验**。

## 2. 数字图像的表示

最简单的 8-bit 灰度图是一张二维像素矩阵。每个像素值在 **0–255**：0 为黑色，255 为白色。图像宽高决定矩阵形状；例如：

```text
原图 f：
  60   90  120
  80  110  150
 100  140  200
```

RGB 图像每个像素有 R/G/B 三个分量。本阶段先以灰度矩阵验证算法与单元测试，后续才扩展到彩色 Bitmap，避免过早引入通道顺序、Alpha 和格式转换问题。

## 3. 高斯噪声（Gaussian noise）：加性随机扰动

### 数学模型

```text
g(x,y) = clip(f(x,y) + n(x,y), 0, 255)
n(x,y) ~ Normal(μ, σ²)
```

- `f(x,y)`：原图像素值。
- `n(x,y)`：随机噪声值。
- `g(x,y)`：添加噪声后的像素值。
- `μ`：噪声均值，常从 0 开始实验。
- `σ`：标准差，决定扰动通常有多大；方差为 `σ²`。
- `clip`：将超出 0–255 的结果裁剪至有效像素范围。

**示例：** 若一个像素原值是 100，本次随机噪声恰好是 +18，则退化值为 118；如果原值是 250，噪声是 +18，退化值会裁剪为 255，而不是 268。

> 注意：高斯**噪声**是一种随机扰动模型；高斯**滤波**是一种加权平滑方法。两者名字相似，但不是同一个算法。

### 参数设计

建议第一组受控实验使用 `μ = 0`，并比较 `σ = 10 / 20 / 35`（以 0–255 像素域为单位）。这些只是待验证的**实验参数**，不代表实际设备测得的噪声强度。

代码验收重点：`σ = 0` 时不改变图像；固定 `seed` 重复运行得到相同结果；不修改原输入矩阵；输出保持合法像素范围。

## 4. 椒盐噪声（Salt-and-pepper noise）：脉冲替换

### 数学模型

对每个像素随机抽取 `u ~ Uniform(0,1)`：

```text
当 0 ≤ u < p_pepper：g(x,y) =   0 （椒：黑点）
当 p_pepper ≤ u < p_pepper + p_salt：g(x,y) = 255 （盐：白点）
否则：g(x,y) = f(x,y)
```

其中 `p_pepper ≥ 0`、`p_salt ≥ 0`，并且必须满足 `p_pepper + p_salt ≤ 1`。

例如设 `p_pepper = 0.02`、`p_salt = 0.02`，每个像素独立地有 2% 概率被置黑、2% 概率被置白，**并不保证每一张小图片恰好有 4% 像素发生变化**。已经为 0 或 255 的像素即使被再次设为相同值，外观上也可能没有变化。

### 参数设计

建议比较总概率 `p = 0.02 / 0.05 / 0.10`，黑、白概率各占一半。固定种子，保持原始输入图片一致，以确保后续滤波器比较公平。

代码验收重点：总概率为 0 时保持原图；非法概率被明确拒绝；输出尺寸与输入尺寸一致；固定随机种子得到可复现结果。

## 5. 为什么要区分噪声类型？

- 加性高斯噪声通常对大范围像素施加幅度不同的扰动。简单平均、Gaussian blur 可以降低部分随机波动，但可能模糊边缘。
- 椒盐噪声呈现零星的亮/暗极值。中值滤波对**低密度脉冲噪声**通常较有效，因为它利用邻域像素的排序统计，不容易被单个极端值拉偏。
- 以上都只是有条件的规律。最终要用控制变量实验比较去噪效果，不能断言某一方法对所有图像与噪声强度都最优。

## 6. 与真实手机夜拍的区别

真实手机弱光成像还受光子散粒噪声（与光子计数相关）、传感器读出噪声、ISP 去噪、JPEG 压缩、曝光时间、手抖等影响。**高斯 / 椒盐只是教学与对照实验常见的简化模型**，不能把它们当成真实夜景噪声的完整分类器。

实际夜景图像的噪声估计与退化分析将在后续模块研究，并需要验证「高频纹理」与「随机噪声」之间可能的混淆。

## 7. 下一步的实现契约（待编码）

优先实现不依赖 Android UI 和 OpenCV 的纯 Kotlin 灰度矩阵函数：

```text
addGaussianNoise(pixels, width, height, mean, sigma, seed) -> newPixels
addSaltPepperNoise(pixels, width, height, pSalt, pPepper, seed) -> newPixels
```

**约束：**
- `pixels` 采用按行排列、长度等于 `width * height` 的整型像素数组。
- 每个输入像素必须处于 0–255；输出依然处于 0–255。
- 无副作用：不修改输入数组，始终返回新的结果数组。
- 参数非法（如负标准差、概率总和大于 1、尺寸不匹配）时抛出明确异常。
- 随机种子必须可传入以便重复实验。
